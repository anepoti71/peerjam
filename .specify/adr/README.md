# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for PeerJam Native.

Per `.specify/memory/constitution.md` Change Policy: any change that bends or breaks a
constitutional principle requires an ADR stored here.

## Index

| ID | Title | Status | Principle affected |
|----|-------|--------|--------------------|
| [ADR-0001](ADR-0001-aoo-as-audio-transport.md) | Use AOO as the audio transport and framing layer | Accepted | II, XI |
| [ADR-0002](ADR-0002-synthetic-audio-for-initial-testing.md) | Synthetic tone for initial integration testing | Accepted | (none — scoped to dev/test) |
